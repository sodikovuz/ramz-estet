INLINE FIX — IMPORTANT

1. @BotFather:
   /setinline
   -> @ramzestetbot
   -> Enable inline mode.

2. Vercel ENV:
   BOT_TOKEN=...
   ADMIN_TELEGRAM_ID=YOUR_NUMERIC_TELEGRAM_ID
   ADMIN_SECRET=...
   PUBLIC_BASE_URL=https://YOUR-DOMAIN.vercel.app
   DATABASE_URL=...
   ABLY_API_KEY=...

3. Redeploy Vercel.

4. Re-register webhook:
   https://YOUR-DOMAIN.vercel.app/api/set-webhook?secret=ADMIN_SECRET

5. Check webhook:
   https://YOUR-DOMAIN.vercel.app/api/telegram-status?secret=ADMIN_SECRET

6. In Telegram type:
   @ramzestetbot 5

If the inline list is empty, the most important field to check is:
ADMIN_TELEGRAM_ID
It must be the numeric Telegram ID of the admin account.
